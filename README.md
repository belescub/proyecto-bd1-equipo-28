Sistema de venta de Helados “Ice SQL”

Ice SQL es un sistema de gestión de ventas para una heladería, orientado al registro y administración de clientes, productos, stock, precios y ventas. 
El sistema permite gestionar el proceso de venta desde la toma del pedido hasta su almacenamiento, incluyendo métodos de pago, presentaciones, sabores y operaciones de caja.
